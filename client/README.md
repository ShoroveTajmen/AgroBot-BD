# AgroBot BD Client

React frontend for the AgroBot BD crop disease advisory system.

## Features

- Chat interface for farmer interaction
- Real-time AI responses
- Advisory display with recommendations
- Session persistence
- Responsive design

## Installation

```bash
npm install
```

## Running

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:3000`

### Production Build

```bash
npm run build
```
